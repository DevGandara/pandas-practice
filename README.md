# Pandas Learning Journey

A collection of Jupyter notebooks documenting my journey learning **Pandas for Data Analysis** using Python.

This repository focuses on understanding essential Pandas concepts through practical examples, hands-on exercises, and data manipulation techniques.

## Learning Objectives

- Understand how to work with Pandas DataFrames and Series.
- Learn how to select, filter, clean, and transform data.
- Perform data aggregation and grouping operations.
- Combine datasets using merging and concatenation.
- Explore datasets using descriptive statistics and visualizations.
- Build a solid foundation for Data Science and Machine Learning.

## Repository Structure

| Notebook | Topics Covered |
|---|---|
| `01-dataframes` | DataFrames, Series, indexing, basic operations |
| `02-selection-filtering` | Data selection, `loc`, `iloc`, conditional filtering |
| `03-cleaning` | Missing values, duplicates, data types, data cleaning |
| `04-groupby` | Grouping, aggregation, `agg()`, `transform()`, `filter()` |
| `05-transformations` | `map()`, `apply()`, `replace()`, `assign()`, conditional transformations |
| `06-merge` | `merge()`, `join()`, `concat()`, SQL-style joins |
| `07-exploratory-analysis` | Descriptive statistics, distributions, correlations, visualizations |
| `08-mini-project` | Applying Pandas concepts to a complete data analysis project (planned) |
